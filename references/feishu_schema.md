# 飞书表结构

## 任务配置表

| 字段名 | 用途 |
|---|---|
| 城市 | 任务城市，也是 BOSS 当前岗位校验和候选人城市硬筛依据 |
| 城市类型 | 读取但暂不参与判断，保留作分层参考 |
| 岗位类型 | 和城市一起组成任务匹配键 |
| 招呼量 | 本轮/今日目标上限 |
| 是否启用 | 未启用不执行 |
| 筛选标准-最低年龄 | 候选人年龄硬筛 |
| 筛选标准-最高年龄 | 候选人年龄硬筛 |
| 筛选标准-活跃度 | 读取；默认手动筛选模式下不自动点击页面筛选 |
| 筛选标准-是否与同事交换简历 | 读取；默认手动筛选模式下不自动点击页面筛选 |
| 细分区域 | 读取；默认手动筛选模式下不自动点击页面筛选 |
| 今日已完成 | 执行后累加回写 |
| 今日剩余 | 控制本次最多还能打多少 |
| 任务状态 | 执行后回写为已完成、提前结束或失败 |
| 最后更新时间 | 执行后回写 |

## 赋分标准

| 字段名 | 用途 |
|---|---|
| 规则名称 | 命中记录展示 |
| 岗位类型 | 规则适用范围 |
| 城市 | 规则适用范围；可多城市 |
| 是否启用 | 未启用不参与评分 |
| 规则类型 | 标记加分、减分、硬过滤等 |
| 作用字段 | 控制匹配候选人的期望、经历、基础信息或全文 |
| 分值 | 命中后的得分变化 |
| 正向词 | 该条规则的正向命中词 |
| 排除词 | 该条规则的排除词；非硬过滤规则命中排除词则本条不计分，硬过滤规则命中则直接过滤 |
| 匹配方式 | 包含任一或包含全部 |
| 计分方式 | 一次性加分或每命中一个加分 |
| 在职时长大于等于(月) | 若填写，正向词必须在同一段经历内命中，且该经历时长达到要求 |
| 最近工作结束间隔大于(月) | 若填写，正向词必须在同一段经历内命中，且该经历结束距今达到要求 |
| 备注 | 读取但不参与评分 |

## 阈值配置

| 字段名 | 用途 |
|---|---|
| 岗位类型 | 阈值适用岗位类型 |
| 城市 | 阈值适用城市；可多城市，城市阈值优先于通用阈值 |
| 是否启用 | 未启用不参与匹配 |
| 通过阈值 | 候选人最终分数需达到该值 |
| 规则版本 | 写入规则摘要，便于追踪 |
| 规则说明 | 每次执行前读取，用于理解当前阈值策略 |

## 飞书读取边界

执行任务前只读取 `任务配置表`、`赋分标准`、`阈值配置`。`任务记录` 和 `打招呼记录` 只在任务结束后回写，不做预读。
